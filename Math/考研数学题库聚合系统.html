数据层与题源说明

当前内置题源：李林考研数学 880 题（数学一）——《高等数学篇》《线性代数＋概率统计篇》结构化解析所得，共 1107 道题，覆盖 3 大科目、23 章、56 个知识点标签。
数据层架构（已实现）
· QuestionAPI 适配层：统一 getQuestions() 入口，当前挂载本地内置 Provider；预留 registerProvider() 可对接主流教辅平台 REST API。
· 筛选结果缓存：FilterCache 以筛选条件指纹为键做 LRU 缓存，并写入 localStorage，重复高频组合秒开。
· 收藏同步：星标收藏持久化于浏览器 localStorage，跨会话保留。
如实说明（未实现 / 限制）
· 纯静态单文件页面，无法真正发起跨域教辅平台登录态请求，外部 API 以适配接口形式预留。
· 源文件为题目分册，不含答案与解析正文、不含真题年份；“解析”以原书页码定位代替，故未设置年份筛选（不编造年份）。
· 少量题目含教材插图，源数据未含图片文件，以「题图」占位标注。
