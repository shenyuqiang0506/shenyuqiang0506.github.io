DFS (Depth-First Search) 可视化教学工具

C 代码执行状态：

bool visited[MaxVertexNum]; // 全局访问数组

void DFS(ALGraph G, int v) {
    visit(v);               // 访问当前顶点
    visited[v] = true;      // 标记为已访问

    // 遍历 v 的所有邻接点
    ArcNode *p = G.vertices[v].first;
    while (p != NULL) {
        int w = p->adjvex;
        if (!visited[w]) {
            DFS(G, w);      // 如果未访问，递归深入
        }
        p = p->next;        // 找下一个邻接点
    }
}
